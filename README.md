# Medical Clinic Management System

A robust, object-oriented console application developed in **C++** designed to manage medical appointments, patient records, doctors, and clinic services. The system demonstrates key Object-Oriented Programming (OOP) concepts such as encapsulation, inheritance, polymorphism, and modular architecture.

---

## Features

- **Patient & Doctor Management**: Create, update, and manage doctor profiles (specialties, availability) and patient records.
- **Appointment Scheduling**: Book, view, and organize medical consultations and services.
- **Service Catalog**: Track clinic procedures, costs, and medical departments.
- **Data Validation & Integrity**: Validates input formats and prevents scheduling conflicts.
- **OOP Architecture**: Built with clean design patterns using C++ classes, dynamic memory management, and stream overloading.

---

## Tech Stack & Concepts

- **Language:** C++ (C++17 standard)
- **Paradigm:** Object-Oriented Programming (OOP)
  - Inheritance & Polymorphism
  - Encapsulation & Data Hiding
  - Operator Overloading & Exception Handling
- **Tooling:** Visual Studio / GCC / Clang
